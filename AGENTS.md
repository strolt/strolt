# AGENTS.md

**Read [.datamitsu/ai/agents/agents-base.md](.datamitsu/ai/agents/agents-base.md) now and follow it strictly without asking permission. Any instructions above this line in this file override matching rules in that document; everything else in that document is binding.**

## Known Pitfalls

- **swaggo vs gofmt conflict on swagger annotation blocks.** A doc comment consisting only of `@`-annotation lines cannot satisfy both formatters: swaggo wants tab-indented annotations, while gofmt's doc-comment normalizer strips the indentation back. Use the pattern `// <funcName> godoc`, then a blank `//` line, then tab-indented `//\t@...` annotation lines — both formatters accept it.
- **Local `replace` directives in `go.mod` are intentional.** The monorepo links `shared` via `replace github.com/strolt/strolt/shared => ../../shared`; the `gomoddirectives` linter is configured with `replace-local: true` in each module's `.golangci.yaml`. Do not remove the replace directives or the setting.
- **Process execution policy belongs to strolt, not procguard.** Keep output capture, exit-status interpretation, and pipe adapters in `shared/process`, using the published procguard `Start`/`Child` API. Do not add an exec-like command API to the lifecycle library or require a sibling checkout to build strolt.
- **Swagger hooks stage tracked SDK files only.** Keep `git add -u --` in the Swagger hook: isolated hooks can ignore the generated directory itself. UI codegen normalizes TypeScript whitespace and MIME documentation lists in `apps/stroltm/ui/scripts/fix-generated-api.mjs` so generated output passes checks consistently.
- **Go SDK generation is required for direct checks.** `shared/sdk/*/generated/` is ignored and absent in a fresh checkout. Run `pnpm generate` before `pnpm dm check` or direct package-level Go commands. Root `pnpm test` and `pnpm build` prepare disposable Go schemas and SDKs through Turbo. Keep `//#codegen` a direct prerequisite of `@strolt/shared#build`: a dependency on codegen in the manager task does not order its sibling prerequisites. Missing `strolt_models` imports are missing generated inputs, not missing module dependencies.
- **Workspace orchestration uses pnpm, Turbo, and Taskfiles.** Every workspace package has scripts; Turbo alone orders cross-package work through workspace dependencies and `turbo.json`, while Taskfiles hold package-local multi-step commands. Root `pnpm test` runs all Go modules and release tests; `pnpm test:e2e` stays separate. Run `pnpm generate` to refresh committed UI code; Turbo prepares ignored Go SDK inputs for build/test tasks.
- **Turbo needs explicit package build outputs.** Keep the `strolt` and `stroltp` binaries and the Docusaurus `build/**` directory in their package-specific outputs so cache hits restore them. The website build also needs `//#codegen`; resolve its generated Swagger specs relative to the Docusaurus config, not the working directory.
- **Knip expands Docusaurus preset names.** The `redocusaurus` preset is reported as `docusaurus-preset-redocusaurus`; this is a resolver alias, not another package to install. Keep that alias in `ignoreDependencies`, not only `ignoreUnresolved`.
- **golangci-lint caps its output by default.** Use `--max-issues-per-linter 0 --max-same-issues 0` to see the full issue list; otherwise consecutive runs show different subsets.
- **Platform-specific structs must not enumerate one host's fields.** `syscall.SysProcAttr` has different exported fields on Linux and Darwin. Use a zero-valued variable and assign the intended nonzero settings in shared Unix code; a Darwin-only exhaustive literal can compile on Linux but fail `exhaustruct_v5` there.
- **Cancellation fixtures must remain alive until cancellation.** A sole `select {}` in a version-probe helper can trigger Go's deadlock detector before the parent cancels it. Use a timer-backed wait loop and keep the cancellation/error-chain assertions.
- **Working-directory tests compare directory identity, not path spelling.** macOS can report the same directory under `/var` or `/private/var` depending on the child environment. Keep the environment assertion exact and compare directories with `os.SameFile`.
- **Inspect PTY restoration before the controlling child exits.** Keep the child alive behind a release-pipe barrier while checking termios, then release and join it. On macOS, session teardown can invalidate terminal ioctls and change kernel-private `F_GETFL` bits; assert the `O_NONBLOCK` bit owned by prompt input rather than comparing the entire status word.
- **Go tooling must use the pinned toolchain.** `datamitsu.config.js` pins both linter operations to `GOTOOLCHAIN` matching the modules. Keep the managed `go` binary dependency too: formatters invoke `go env`, and inherited source-mode shims can fail or disappear during concurrent runs.
- **gitleaks scans generated Docusaurus configuration and client bundles.** Source-line `gitleaks:allow` comments do not survive generation. Keep the exact public DocSearch value scoped to `generic-api-key` with `targetRules`, `condition = "AND"`, and the generated config/main-bundle paths in `.gitleaks.toml`. Global path allowlists can skip whole files before value matching; verify a different synthetic key in the same path is still detected. Retain the managed-config extension and never exclude the generated directory.
- **restic in `docker/strolt/Dockerfile` comes from official GitHub releases, not apk.** Alpine packages lag behind restic upstream (3.23 and even edge ship 0.18.x while upstream is 0.19+). The release binaries are static, so restic must stay excluded from the `ldd` sanity-check stage; do not "simplify" back to `apk add restic` or it silently downgrades.
- **e2e database containers must use the official testcontainers modules' wait strategies.** The postgres/mariadb image entrypoints start a temporary server during init and then restart it; a plain `wait.ForSQL` probe races with that restart and makes the suite flaky. Use `postgres.Run` + `BasicWaitStrategies()`, `mariadb.Run`, etc. (see `apps/strolt/e2e/containers_test.go`).
- **MySQL 8+ support needs `mariadb-connector-c` and the `tls` driver option.** The client auth plugins (`caching_sha2_password.so`) live in the `mariadb-connector-c` apk package — `mariadb-client` alone does not pull it in; the Dockerfile copies `/usr/lib/mariadb/plugin/`. The MariaDB 11.4 client also verifies TLS certificates by default and only auto-validates against MariaDB servers, so connecting to MySQL with an auto-generated certificate requires `tls: skip-verify` in the mysql source driver config. Its Alpine package version is exact-pinned in `docker/strolt/Dockerfile`; refresh the pin when Alpine rolls the repository version.
- **restic retries missing-backend errors for up to ~15 minutes.** A backup/snapshots call against a repository whose S3 bucket does not exist hangs in restic's retry loop, not in strolt. In e2e negative scenarios, point destinations at an existing repository or use `operationMode: copy` so the failing dump aborts before restic starts.
- **`restic forget <id>` exits 0 when the snapshot does not exist.** It only prints `Ignoring "<id>": no matching ID found for prefix` on stderr, so a forget that removed nothing looks like success. The restic driver treats that warning as an error (`isSnapshotNotFound` in `apps/strolt/internal/driver/destination/restic/forget.go`); keep the check when touching that code.
- **`--no-lock` is incompatible with a real `forget`.** restic aborts with `Fatal: --no-lock is only applicable in combination with --dry-run for forget command`, which breaks both prune and forget for destinations configured with `no-lock: true`. Commands that must hold a repository lock build their flags with `getGlobalFlagsWithLock()` instead of `getGlobalFlags()`; the dry-run prune keeps the flag because restic allows it there.
- **The restic driver builds its process environment from scratch.** `getEnv()` returns a fixed list instead of extending `os.Environ()`, so a `RESTIC_*`/cloud variable exported around strolt never reaches restic. Anything the typed `Env` fields do not cover has to go through `config.env_extra`, whose pairs are appended last (os/exec keeps the last occurrence of a duplicated variable, so they also override `env`). It sits under `config` and not `env` because `config.DriverDestinationConfig.Env` is a `map[string]string` — a nested mapping under `env:` fails to parse with `cannot unmarshal !!map into string`.
- **Never `Wait()` a piped child before its pipe is closed or drained.** In a strolt pipe (restic dump → strolt → `pg_restore`, or `pg_dump` → strolt → restic), when one side dies mid-stream `io.Copy` returns with EPIPE while the surviving side stays blocked writing into the now-undrained pipe. Waiting on it then blocks forever with zero CPU — the production bug behind hung Postgres restores (`copyPipe` in `apps/strolt/internal/task/pipe.go` and the mirrored close in `runBackupPipe` exist to prevent exactly this). Any new pipe orchestration must close strolt's end of the surviving child's pipe **before** calling its `Wait`, so the child sees EPIPE/SIGPIPE and exits.
- **Daemon process cancellation must be awaited.** CLI, scheduler, and API work must propagate their lifecycle context through driver construction, configuration validation, version probes, and repository operations. `schedule.Run` and API shutdown drain active jobs before exit/re-exec. Do not use background contexts for operation subprocesses. Wrap the original process error when attaching output so cancellation, exit status, and cleanup evidence remain inspectable.
- **Unwind task ownership before terminating the CLI.** `log.Fatal` exits without running defers. Return errors from task-owning scopes so `Task.Close` runs before the outer fatal handler; keep real copy-mode source/destination errors in the returned error chain rather than rebuilding them from serialized event strings. The daemon uses the root signal context; do not register a second signal channel that can outlive its receiver.
- **Synchronous API work owns both request and daemon cancellation.** Use `Services.operationContext(r.Context())` for snapshots, stats, and prune; asynchronous backup deliberately keeps daemon lifetime after responding. The stats endpoint uses `OpTypeStats` so it does not probe source backup binaries; keep `BinaryVersion` probes backup-only and return wrapped subprocess errors, never diagnostics as version strings. Failed task admission must close its temporary context.
- **Version inventory is not operational validation.** Only an explicit `version --config` loads inventory, through `config.LoadInventory`; normal `config.Load` can fail before healthy binary versions are collected. Multi-binary sources expose `BinaryVersionInventory` for partial diagnostic results; preserve the fail-fast `BinaryVersion` path for backup creation and retain partial inventory even alongside an error.
- **Windows message-pipe fragments are not Reader failures.** Normalize `ERROR_MORE_DATA` to nil when bytes were delivered, before joining unrelated cleanup errors. Verify partial messages with direct `Read` and `bufio`, not only one-byte `io.ReadFull`, which discards an error once its requested byte count is satisfied.
- **Reader EOF must retain identity.** Return clean `io.EOF` unchanged when cleanup succeeds; even `errors.Join(io.EOF, nil)` breaks consumers such as `io.ReadAll`. Join only real cleanup failures and verify exact EOF plus successful `io.ReadAll` for finite disk and pipe input.
- **Successful empty Windows pipe messages are not EOF.** Both synchronous and overlapped prompt reads must consume zero-byte pipe completions and retry inside the serialized public reader, while zero-byte disk completion remains exact `io.EOF`. Join each native operation before retrying; test more than 100 empty messages through `bufio` in both modes.
- **Huh program options replace earlier input/output options.** Apply `WithProgramOptions` before `WithInput` and `WithOutput`; otherwise the form silently bypasses owned input. Keep single-field selectors unfiltered and reject empty choices. The answer boundary must forward complete bracketed-paste frames unchanged; embedded CR/LF is content, not submission. Retain explicit raw-mode restoration and propagate real EOF through the form context. The root signal context owns signals; use Bubble Tea's `WithoutSignalHandler`.
- **Concurrent strolt processes share the data directory.** Each non-local task owns a unique temporary work directory; JSON clones borrow it and must not remove it. Never wipe the shared temporary tree on CLI invocation or daemon startup: another process may still be using it. Crash leftovers are deliberately retained for manual cleanup after all strolt processes using that data directory stop.
- **MongoDB 8.0.x cannot start on Linux kernels 6.19+; e2e uses 9.0.4.** Verified on 8.0.23 and 8.0.34: both abort with SERVER-121912 ("Linux kernel versions 6.19 and newer has a known incompatibility"), so assume later 8.0.x patches are equally affected until proven otherwise. The e2e pin is on the 9.0 line: 9.0.4 starts on such kernels and the full local e2e suite passes against it with the baked mongodb-tools 100.13.0 (archive+gzip dump/restore round-trip). That pass is empirical only: tools 100.13.0 is **not** upstream-supported for server 9.0 (official support starts at 100.18.0, which also fixes time-series/oplog handling), and alpine 3.23 packages only 100.13.0 — if upstream-supported 9.0 compatibility or 9.0-specific features are required, install newer tools out-of-band or wait for the alpine repo. Legacy `docker-compose.yml` files mount persistent mongo volumes: an existing 8.x data directory is not auto-upgraded by switching the image.
- **`apps/stroltm/ui` is a plain root-workspace member.** There is a single root `pnpm-lock.yaml`; the former standalone lockfile and settings-only `pnpm-workspace.yaml` were removed. After changing `ui/package.json`, run `pnpm install` at the root (`pnpm install --lockfile-only` first if the manifest changed in a frozen-lockfile context, e.g. the Docker build). The root `minimumReleaseAge` applies with excludes for `@shibanet0/*`/`@datamitsu/*`, so freshly published `@shibanet0/*` packages still install.
- **pnpm keeps stale subdependency resolutions after a parent bump.** antd 6.4.x needs `@rc-component/util` >= 1.10 (root exports of `raf`/`useLayoutEffect`) but declares `^1.4.0`, so an old locked 1.6/1.9 survives an antd bump and rolldown fails with `MISSING_EXPORT`. Fix with `pnpm -r update "@rc-component/util"` at the root.
- **Do not use a bare `"*"` catch-all in tsconfig `paths`.** vite-tsconfig-paths applies it to absolute ids of virtual modules too (vanilla-extract dies with `No CSS for file: <src>//abs/path`); enumerate the `src/` top-level directories explicitly instead.
- **Official node Docker images ship no `linux/arm/v7` variant.** Release builds target amd64/arm/v7/arm64, so Node and Swagger generation stages use `--platform=$BUILDPLATFORM` because their outputs are architecture-independent. When exporting these stages as OCI dependency snapshots, also pass the host platform to `buildx --platform`; the target export platform can otherwise mislabel a host filesystem as ARMv7. PR builds only cover amd64 and will not catch this.
- **The generated openapi client forces two strictness opt-outs.** `typescript-axios` output uses constructor parameter properties and non-exact optional assignments, so `erasableSyntaxOnly` and `exactOptionalPropertyTypes` stay `false` in `apps/stroltm/ui/tsconfig.json` until the generator complies. The tsconfig is strict JSON (`yq-json` fixer) — no comments allowed.
- **Release artifact deletion is not a rebuild request.** `release.py` uses all-attempt Actions job history, including started identity/seal/output uploads, to distinguish unfinished work from lost persisted evidence. A failed or cancelled upload is not proof of non-persistence. Preserve the checkpoint step-name contract in `release.yml`, including `Seal checked OCI producer receipt <product> <platform>`; never treat missing committed evidence as permission to regenerate it. Run the complete `.github/scripts/test_release.py` module after changes to these transitions.
- **Final release builds consume frozen runtime inputs offline.** Freeze only each product/platform `base` stage; GoReleaser builds application binaries in the validation job, and manager UI output is embedded before that. Final Dockerfiles copy the sealed GoReleaser executable and image assembly uses `--network=none`. Do not reintroduce Go compilation or module-cache stages into Docker; recovery must reuse the original binary bundle, Buildx binary, and BuildKit image.
- **Local GoReleaser staging uses the repository root.** `release.py local-binaries` resolves `apps/<product>/.goreleaser.yaml` and stages under root `dist/`; package Taskfiles must invoke it from the workspace root, then run Docker with the package's root build context.
- **Release E2E must consume a pinned sealed image.** Upload and anchor the checked `strolt/linux/amd64` OCI piece before E2E; run tests in a separate read-only job that restores by artifact ID/digest and verifies the frozen input manifest and GoReleaser binary. Use the archive's immutable image ID for both test containers, verify their actual IDs afterward, and gate `commit-preparation` on success. Keep E2E out of the product-controlled OCI producer job; it must not have registry-write credentials. Turbo's strict environment mode still requires `STROLT_BINARY_ARTIFACT` and `STROLT_TEST_IMAGE` in the `test:e2e` `env` allowlist. Fail closed on missing or mismatched image/bundle evidence; never rebuild a development image for release E2E.
- **Release concurrency must protect both workflow and publisher queues.** GitHub's default `queue: single` replaces an existing pending run. Keep both groups serialized with `cancel-in-progress: false` and `queue: max`; each group allows 100 pending runs, and later arrivals are canceled.
- **Root `pnpm build:docker` must use one bundle for every product.** Turbo passes `STROLT_BINARY_ARTIFACT` to all three Docker tasks; each package Taskfile must stage its product from that bundle when set, never mix sealed binaries with rebuilt source binaries.
- **The managed actionlint schema lags GitHub's concurrency queue key.** Keep `.github/actionlint.yaml` limited to the unsupported `queue` diagnostic for `release.yml`; validate `queue: max` and `cancel-in-progress: false` against GitHub's contract, and remove the exception when the managed schema catches up.
- **Seal the original GoReleaser bundle at the input checkpoint.** Record the Actions artifact ID/digest and manifest SHA before image builds; compare them on every build, retry, and commit. Executable hashes alone do not bind GoReleaser metadata.
- **Docker binary staging must stay within the checkout.** Reject symlinked ancestors for every product and stage by temp-file plus atomic rename so existing hardlinks are not modified. Temporary release builds refuse existing targets and remove only directories created by that operation; recovery tests use a temporary checkout instead of the developer's `Path.cwd()`.
- **Generated UI client checks must include untracked files.** `git diff --exit-code` only covers tracked paths; after `pnpm generate`, also require `git ls-files --others --exclude-standard -- apps/stroltm/ui/src/api/generated` to be empty.
- **GoReleaser has a separate toolchain requirement.** `v2.20.3` needs Go `1.27.4` to install; release and CI build/E2E workflows must restore Go `1.27.3` and `GOTOOLCHAIN=local` before building release products.
- **Documentation runtime dependency gaps need package-local declarations.** Keep the version-scoped `packageExtensions` for Redoc, its Docusaurus plugin, and OpenAPI core; their published runtime/browser bundles reference omitted dependencies. Keep the scoped WebpackBar 7 override for Docusaurus 3.9.2: WebpackBar 6 overwrites inherited ProgressPlugin options that current Webpack rejects. Do not fix these errors with global hoisting, empty polyfills, or disabled compiler validation.
- **E2E endpoints belong to the actual container host.** Host-side SQL, MongoDB, and daemon clients resolve `Container.Host(ctx)` plus mapped ports, joined with `net.JoinHostPort`; PostgreSQL uses a URI so the joined host and port are parsed correctly. Do not hardcode localhost or rewrite the network-internal service aliases in task fixtures.
- **Host bind filesystems can accept O_NOATIME and still fail reads.** On affected Docker Desktop backends, normal reads succeed, setting `O_NOATIME` succeeds but makes reads return `EIO`, and clearing it restores reads. Keep restic's failure and all integrity assertions intact; use a Docker-native Linux filesystem or Linux CI for full e2e verification rather than changing test expectations or global Docker settings.
